Fill in the following information to generate a number wall
It will appear as a.png in the 2026MURA directory
(assuming generation is successful)

pixel_size:      1
modulo:          2

======================================

number_wall_type:     1
(see below)

square_wall:          1
(boolean 1 or 0, see notes)

======================================

Number Wall types

1 - uses frame constraint equations (default)

2 - uses determinants of sequence Toeplitz matrices

3 - uses permanants of sequence Toeplitz matrices

4 - uses 3D equivalent of determinant of 3D Toeplitz tensor

======================================

sequence_generation_option:    1
(See below)

======================================

Option_1 - A sequence in the sequences folder

sequence_name:     thue_morse
max_width:         1023

(see notes below for list of sequence files)

======================================

Option_2 - A sequence in a specified file

sequence_name:     sequences/pagoda.txt
max_width:         1000

(must be in OEIS b-file format (see notes below))

======================================

Option_3 - A sequence generated from a given morphism

start_symbol:            1
number_of_iterations:    7

morphism_(below):

1
1 0

0
1

======================================

Option_4 - A custom sequence entered here

sequence_(below):

3 1 4 1 5 9 2 6 5 3 5 8

======================================

Notes:

- modulo 0 means no modulo (original wall will be displayed),
    currently, only Number Wall type 1 supports this feature

- if nonzero, modulo must be a prime less than 1000

- if square_wall is set to 1, it will assume 0s to the
    left and right of the sequence to make a square wall
    instead of the usual triangle

- do not add ".txt" to files from the sequences folder

- a suffix of "_(below)" means the values should be entered
    in the line(s) below the input name

- symbols in morphisms must be integers

- an OEIS b-file is a file where where each line consists
    of the index followed by the sequence value, for example,
    1 2
    2 3
    3 5
    4 7
    ...
    9998 104717
    9999 104723
    10000 104729
