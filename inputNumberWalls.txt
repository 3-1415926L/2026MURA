======================================

Number Wall types:

1 - uses frame constraint equations (default)

2 - uses determinants of sequence Toeplitz matrices

3 - uses permanants of sequence Toeplitz matrices

4 - uses 3D equivalent of determinant of 3D Toeplitz tensor

======================================

Notes:

- modulo 0 means no modulo (original wall will be displayed),
    currently, only Number Wall type 1 supports this feature

- if nonzero, modulo must be a prime less than 1000

- if square_wall is set to 1, it will assume 0s to the
    left and right of the sequence to make a square wall
    instead of the usual triangle

- in square number walls, the information to the right of the
    y=x line often looks random if the original sequence is
    not supposed to have zeros to the right of it

- you must be using a square number wall to look for a morphism

- when saving a Number Wall image, it will appear as a.png in
    the 2026MURA directory (assuming generation is successful)

- checkFC1 will almost certainly fail if not using one of
    the main two Number Wall definition

- morphisms from the morphism finder are assumed to be square

- min_iters_for_unique is the minimum number of iterations of
    the morphism required to uniquely determine which symbol
    you started with from the 0 positions in the resulting grid

- do not add ".txt" to files from the sequences folder

- a suffix of "_(below)" means the values should be entered
    in the line(s) below the input name

- symbols in input morphisms must be integers

- an OEIS b-file is a file where where each line consists
    of the index followed by the sequence value, for example,
    1 2
    2 3
    3 5
    4 7
    ...
    9998 104717
    9999 104723
    10000 104729
